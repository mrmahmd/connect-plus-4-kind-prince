# The Kindness Quest — The Kind Prince and the Bird

Interactive **Connect Plus Grade 4, Unit 3, Lesson 4: Literature Corner**, based on the user-supplied textbook pages **42–43**. English only. Chapter labels do not display lesson minutes.

## Run and publish

Open `index.html` locally, or serve this folder with a static web server. No build, account, API key or package installation is required. For GitHub Pages, publish `main` from `/ (root)`. Script and stylesheet URLs are versioned to avoid stale assets after updates.

## Teaching sequence

The Teacher desk (password **1927**) holds the complete 40-minute plan and answer key. It re-locks on closing. This is a browser-side classroom gate, not server authentication: the static source remains public.

| Chapter | Minutes | Purpose |
| --- | --- | --- |
| Your mission | 3 | Textbook Look and discuss, prediction, objectives |
| Word treasures | 5 | Vocabulary, story expressions, five meaning matches |
| Story theatre | 10 | Complete printed story in six illustrated scenes, explanations and evidence |
| Book Lab | 16 | Every page-43 task: six ordered events, eight gaps and six written answers |
| Bonus quest | 3 | Selected closed questions; remaining items for independent practice |
| Kindness in action | 3 | Community discussion, short writing plan and exit ticket |

The time guide supports a 40-minute class. Learners can finish extended writing and extra practice afterwards.

## Book-page coverage

- **Page 42 exercise 1:** all three Look and discuss questions, with possible responses.
- **Page 42 exercise 2:** full supplied story, optional device-generated English reading, six illustrated scenes, explanations and comprehension checks.
- **Page 43 exercise 3:** all six original statements, with letter labels retained; HTML drag-and-drop and keyboard/touch arrow controls.
- **Page 43 exercise 4:** all eight original gap sentences; optional word bank, individual clues and spelling-tolerant checking (case, surrounding spaces and punctuation).
- **Page 43 exercise 5:** all six original comprehension questions, saved written responses, clues, model answers, textual evidence and explicit self-review. Different correct wording is welcome; responses are reviewed by the teacher rather than algorithmically graded.
- **Think! / What do we learn?:** community discussion, practical examples, a personal kindness plan and the supplied moral.

## Ordering ambiguity handled explicitly

The printed dialogue states the Prince’s sadness after the bird arrives: **d–a–b–e–c–f**. It is also reasonable to infer sadness when the Prince first notices people in need: **d–b–a–e–c–f**. Both orders are accepted. The Teacher desk explains the distinction. No single unsupported answer is imposed.

## Progress and feedback

There are **33 best-practice stars**: 5 vocabulary + 6 event-order + 8 gaps + 6 MCQ + 5 true/false + 3 cause/effect. Completing either coherent full event order awards the six ordering stars. Written responses earn a separate Book Lab completion badge through writing and self-review; this is explicitly not automatic marking. A quest card accurately reports current progress, including unfinished progress.

Drafts, settings and progress are stored in localStorage only on the current device. Text/SVG downloads are generated locally. No student data is uploaded. Reset clears stars and review badges but keeps written work.

## Design and accessibility

Original code-native SVG city, Prince and bird illustrations; responsive layouts; bold readable type; visible focus; native labels and controls; reduced-motion support; larger text; projector mode; keyboard/touch alternatives to dragging. Optional Google Fonts has system-font fallbacks. The reading voice is generated by the visitor’s device and is not the book audio. No third-party JavaScript is used.

## Source boundaries

The printed textbook adaptation is transcribed from the two supplied images. No additional events from other versions of the Happy Prince are added. Explanations, vocabulary definitions, original illustrations, model responses and extra practice are teaching support. The original screenshots are not republished. Page questions are retained verbatim, including the wording of question 4.
